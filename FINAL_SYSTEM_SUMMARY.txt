ARCHITECTURE
═══════════════════════════════════════════════════════════════════════════════

FLOW:
  1. User initializes grid via Streamlit UI
  2. MCP server creates drone swarm and places survivors/obstacles
  3. User launches mission with model selection and briefing
  4. Mission controller sends full state to AI model (single prompt)
  5. AI returns JSON plan with drone assignments
  6. Plan executor parses and validates JSON
  7. Drones execute continuously until completing assignments
  8. Battery monitoring triggers reassignment if < 20%
  9. Mission completes when all survivors found

CORE FILES:
  Environment:
    - environment/grid.py: Grid system with bottom-left origin
    - environment/drone.py: Drone logic, movement, scanning

  Orchestration:
    - orchestrator/mission_controller.py: Mission lifecycle orchestration
    - orchestrator/plan_executor.py: JSON plan parsing and execution
    - orchestrator/single_shot_prompts.py: AI prompt templates
    - orchestrator/model_loader.py: Dynamic model selection

  Server:
    - mcp_server/server.py: FastMCP server with drone control tools

  UI:
    - ui/app.py: Streamlit dashboard with map visualization

HOW TO DEPLOY
═══════════════════════════════════════════════════════════════════════════════

1. START MCP SERVER (Terminal 1):
   uvicorn mcp_server.server:app --reload --port 8000

2. START STREAMLIT UI (Terminal 2):
   streamlit run ui/app.py

3. OPEN BROWSER:
   http://localhost:8501

4. INITIALIZE ENVIRONMENT:
   - Set grid width: 20 (or desired size)
   - Set grid height: 20
   - Set drones: 3
   - Set survivors: 5
   - Click "Initialize Environment"

5. CONFIGURE MISSION:
   - Select AI model from dropdown (default: Nvidia Nemotron)
   - Enter optional mission briefing
   - Click "Launch ARIA"

6. WATCH EXECUTION:
   - Mission log shows AI reasoning and drone actions
   - Map visualizes drone positions and discovered survivors
   - Mission completes when all survivors found

TROUBLESHOOTING

  - Verify all dependencies installed: pip install -r requirements.txt
